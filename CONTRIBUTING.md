# Contribution au Projet SlopKit

Merci de votre intérêt pour contribuer à SlopKit! Ce guide vous explique comment bien contribuer.

## 📋 Code de Conduite

- Respectez tous les contributeurs
- Pas de spam ou de contenu offensant
- Signalez les abus aux mainteneurs

## 🐛 Signaler un Bug

### Avant de Signaler
1. Consultez le [Guide de Dépannage](TROUBLESHOOTING.md)
2. Vérifiez que le bug n'a pas déjà été signalé
3. Notez les messages d'erreur exacts

### Créer une Issue

```markdown
**Titre**: [BUG] Description courte du problème

**Firmware PS5**: (ex: 12.50)
**Type Connexion**: (Filaire / WiFi)
**Erreur Exacte**: (Copiez le message complet)

**Étapes pour Reproduire**:
1. ...
2. ...
3. ...

**Résultat Attendu**: ...
**Résultat Obtenu**: ...

**Déjà Essayé**: 
- [ ] Redémarrage
- [ ] Changement de réseau
- [ ] Nouveau firmware
```

## 💡 Proposer une Amélioration

Ouvrez une issue avec le tag `enhancement` décrivant:
- Quel problème résout cette amélioration?
- Comment ça fonctionne?
- Des alternatives considérées?

## 🔄 Pull Requests

### Avant de Soumettre
1. Fork le repository
2. Créez une branche: `git checkout -b ma-feature`
3. Commitez vos changements: `git commit -m "Description"`
4. Pushez: `git push origin ma-feature`
5. Ouvrez une Pull Request

### Règles de Qualité
- ✅ Le code doit être lisible
- ✅ Commentaires sur le code complexe
- ✅ Tests si applicable
- ✅ Documentez les changements
- ✅ Pas de fichiers secrets/credentials

### Description de PR

```markdown
**Quoi**: Description brève du changement
**Pourquoi**: Problème que cela résout
**Comment**: Comment ça marche

Fixes #123 (remplacez par le numéro d'issue)
```

## 📚 Documentation

Les améliorations de documentation sont toujours bienvenues!

- Corrections de typos
- Clarifications
- Traductions
- Nouveaux guides de dépannage

## 🎯 Domaines Recherchés

- Tests de stabilité sur différents firmware
- Optimisations de performance
- Améliorations UI/UX
- Documentation / Traductions
- Outils de diagnostic
