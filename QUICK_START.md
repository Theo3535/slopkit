# 🚀 Démarrage Ultra-Rapide - 5 Minutes

## Prérequis Absolus
- ✅ PS5 firmware 9.00-13.00
- ✅ Connexion Internet stable
- ✅ Navigateur Web PS5
- ✅ 10 GB espace libre

## Matrice de Compatibilité Firmware
- ✅ **9.00-13.00**: jailbreak + chargeur ELF + payload sender disponibles
- ❌ **Autres versions**: non supportées

## 3 Étapes Simples

### 1️⃣ Accès (1 minute)
```
1. Sur la PS5, ouvrez le Navigateur Web
2. Allez sur: https://theo3535.github.io/slopkit/
3. Attendez le chargement complet (vous verrez un gros bouton)
```

### 2️⃣ Exécution (2-3 minutes)
```
1. Appuyez sur le bouton "Jailbreak"
2. NE FERMEZ PAS le navigateur
3. Attendez (vous verrez des messages)
4. La PS5 redémarrera si succès
```

### 3️⃣ Vérification (30 secondes)
```
✅ SUCCÈS: Le flux compatible avec votre firmware s'est exécuté
❌ ERREUR: Voir section Dépannage Rapide ci-dessous
```

---

## 🆘 Dépannage Rapide (Choisissez Votre Erreur)

### ❌ "UNLUCKY — YOU NEED TO REBOOT"
```
→ Appuyez Power 10 secondes jusqu'extinction
→ Attendez 1 minute
→ Rallumez et réessayez
```

### ❌ "trigger fired"
```
→ Utilisez Ethernet filaire (pas WiFi)
→ Fermez toutes les apps
→ Attendez 5 minutes
→ Réessayez
```

### ❌ "descriptor left open"
```
→ Redémarrage obligatoire
→ Maintenez Power 10 sec → extinction
→ Attendez 1 minute
→ Rallumez et réessayez
```

### ❌ "setuid called X times"
```
→ Pareil que "descriptor left open"
→ C'est normal, redémarrez juste
→ Ne vous inquiétez pas, ce n'est pas endommagé
```

### ❌ "payload fetch failed"
```
→ Vérifiez Internet (ouvrez google.com dans navigateur)
→ Si Google charge: Attendez 10 min et réessayez
→ Si Google ne charge pas: Problème Internet
```

## ⚡ Conseils de Succès

| Faites | Ne Faites Pas |
|--------|--------------|
| ✅ Utilisez Ethernet | ❌ WiFi loin du routeur |
| ✅ Console allumée et connectée | ❌ Ne fermez pas le navigateur |
| ✅ Écran allumé pendant exploit | ❌ N'appuyez sur aucun bouton |
| ✅ Attendez 2-3 minutes | ❌ Ne redémarrez pas trop vite |
| ✅ Réessayez après redémarrage | ❌ Abandonnez après 1 tentative |
